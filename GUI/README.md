# UD85C08_GUI

Ce dossier accueillera le projet MFC `UD85C08_GUI.vcxproj`.

Contrairement a `Core` et `CLI`, un projet MFC (boite de dialogue, ressources
.rc, fichiers generes par l'assistant) se cree plus fiablement via l'assistant
"Application MFC" de Visual Studio 2022 que par creation manuelle de fichiers.

Voir les instructions dans le README.md a la racine du depot pour la marche
a suivre exacte.
